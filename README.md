#  DNA Sequence Analyzer

A Python-based bioinformatics tool for analyzing DNA sequences entered by the user. The program performs basic sequence analysis and biological transformations such as nucleotide counting, GC/AT content calculation, reverse complement, transcription, and amino-acid translation.

##  Project Objective

The objective of this project is to build a beginner-friendly DNA sequence analysis tool using Python while applying programming concepts to a real bioinformatics problem.

##  Features

- Take DNA sequence input from the user
- Convert the sequence to uppercase
- Validate the DNA sequence
- Count A, T, G, and C nucleotides
- Calculate GC content
- Calculate AT content
- Generate the reverse complement
- Transcribe DNA into RNA
- Identify codons
- Translate codons into an amino-acid sequence
- Display analysis results clearly

##  Bioinformatics Concepts

This project demonstrates basic concepts of DNA sequence analysis, including:

- Nucleotide composition
- GC and AT content
- Complementary DNA bases
- Reverse complement
- DNA → RNA transcription
- Codons
- DNA → protein translation

##  How to Run

1. Open the Jupyter Notebook in Google Colab.
2. Run the cells in order.
3. Enter a DNA sequence when prompted.
4. The program validates and analyzes the sequence.
5. The results are displayed in the notebook.
